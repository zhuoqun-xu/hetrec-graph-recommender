# Abstract — HetRec Movie Recommendation Experiment

This project reimplements a heterogeneous-graph representation idea from a 2021 undergraduate thesis for warm-user, warm-item Top-20 movie recommendation. On HetRec 2011 MovieLens-2k v2, movies are linked through shared actors and directors. For each meta-path, the model samples movie neighbors, combines their learned ID vectors with the target movie vector using mean aggregation, and fuses the self, actor and director branches with movie-level attention. Learned user vectors and a BPR pairwise objective turn the movie representations into a recommender.

Ratings are split chronologically into train, validation and test. Evaluation ranks the full warm-item catalog, excludes previously rated movies, and reports user-averaged Recall@20 and NDCG@20. A matched shuffled-link model tests whether the identity of actor/director relations matters. On the cleaned test set, the real graph achieves Recall@20 of 0.0882 and NDCG@20 of 0.0887, below user-based collaborative filtering (0.1151, 0.1148) and the shuffled graph (0.0915, 0.0920). Thus, the current implementation shows no recommendation gain from the real movie relations. The extended training run is exploratory because initial test results had already been viewed; retrospective metadata and the ID-based warm-item setting further limit the conclusion.
